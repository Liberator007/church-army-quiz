# Викторина — заметки для Claude

## Устройство сайта

- Статический сайт без сборки: `index.html`, `css/style.css`, `js/data.js` (содержимое), `js/app.js` (движок), `js/sound.js` (сигналы таймера).
- Структура взята из `Liberator007/homechurch-quiz`. Вся викторина — один раунд вопросов с вариантами ответа.
- Вопросы — со страницы «Викторина» в Notion (раздел «Армия»):
  https://app.notion.com/p/405a841aabe4808fbcb8c7af0a73a0d7 — сайт повторяет её (`js/data.js`).
- Порядок слайдов: заставка → все вопросы (номер → вопрос с вариантами + таймер сбоку) →
  «Ответы» → по слайду на ответ (клик подсвечивает правильный вариант и показывает картинку `image`) → конец.
  Запасные вопросы (`spare`) скрыты из обычного показа, открываются через O; их ответ появляется, если вопрос показывали.
- Команд и подсчёта очков на сайте нет — только вопросы, время и ответы.
- При изменении вопросов, времени или порядка показа обновлять и `README.md`.
- Стиль — армейские тона: тёмная тема «ночная олива», светлая «хаки», акцент — латунь.
  Без камуфляжа, сетки и звёзд (пользователь попросил убрать): фон — мягкое свечение по углам.
- localStorage — с приставкой `army-quiz:`, чтобы не путаться с другими викторинами, открытыми с диска.
- Время меняем только по прямой просьбе пользователя.
- Проверка: скриншоты через Playwright из scratchpad.
