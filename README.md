# Армейская викторина

Сайт-презентация для проектора: показывает вопросы, время на ответ и ответы.
15 вопросов на армейскую тему, у большинства — 4 варианта ответа. Вопросы берутся со страницы
«Викторина» в Notion (раздел «Армия»). Оформление — в армейских тонах (олива, хаки, латунь).
Работает **без интернета** и без установки — это обычные HTML-файлы.

Структура и управление взяты из викторины [homechurch-quiz](https://github.com/Liberator007/homechurch-quiz).

## Как запустить

1. Скачать репозиторий: на GitHub **Code → Download ZIP** (или `git clone`), распаковать.
2. Открыть `index.html` в **Google Chrome** (двойной клик).
3. Перетащить окно на проектор и нажать **F** — полный экран.

Если что-то не грузится из файла (бывает в некоторых браузерах), запустите маленький сервер
в папке проекта и откройте http://localhost:8000:

```
python3 -m http.server 8000
```

## Как устроен показ

**Заставка → вопросы → ответы → конец.**

- Вопрос: сначала на экране только его номер, по клику открывается вопрос с вариантами и запускается время
  (15 секунд, таймер справа). Следующий клик — следующий вопрос.
- После всех вопросов — ответы, по слайду на каждый вопрос: сначала вопрос с вариантами, по клику
  подсвечивается правильный вариант (или появляется ответ, если вариантов нет) и картинка, если она есть.
  Следующий клик — следующий ответ.
- Запасной вопрос открывается через **O**; если его показывали, его ответ появится среди ответов.
- Если номер перед вопросом не нужен, поставьте `numberFirst: false` в начале `js/data.js`.

## Управление

| Клавиша | Что делает |
|---|---|
| **Клик мышью**, **→**, **Пробел**, **PgDn** | Дальше: открыть вопрос и запустить время → следующий вопрос → открыть следующий ответ |
| **Правый клик**, **←**, **PgUp** | Назад (на слайде ответа — снова скрыть ответ) |
| **P** | Пауза / продолжить время |
| **R** | Запустить время заново |
| **O** | Список всех слайдов, переход в любое место, **запасные вопросы** |
| **F** | Полный экран |
| **T** | Светлая («хаки») / тёмная («ночная олива») тема |
| **B** | Чёрный экран |
| **M** | Выключить / включить сигналы таймера |
| **H** | Подсказка по клавишам |

Пульт-презентер работает (он нажимает PgUp / PgDn). Клавиши работают и в русской раскладке.
При движении мышью в правом нижнем углу появляются кнопки ведущего.
Сайт запоминает, на каком слайде вы остановились.

## Бланк ответов

`blank.pdf` — готовый лист A4 для печати: на нём 6 бланков (2 × 3, каждый 105 × 99 мм), между ними
пунктир для разрезания. В бланке поле для имени и две колонки по 8 строк.
У вопроса с вариантами в строке кружки 1–4 (их обводят), у вопроса без вариантов — линия для ответа.
16-я строка — для запасного вопроса.

Бланк строится из вопросов в `js/data.js`: если вопросы поменялись, откройте `blank.html` в Chrome
и распечатайте его (**Ctrl+P**, формат A4, поля — «Нет»), либо пересохраните из этого окна `blank.pdf`.

## Как поменять тексты

Все вопросы, ответы и время — в файле `js/data.js`. Его можно редактировать прямо на GitHub.

- `title`, `subtitle` — заголовок и строка над ним (дата, событие) на заставке.
- `phases` — время на вопрос (можно несколько фаз — тогда под таймером появится их список).
- `questions` — вопросы: `text` — вопрос, `options` — варианты, `correct` — номер правильного (с 1),
  `answer` — ответ словами (если вариантов нет), `note` — пояснение, `image` — картинка к ответу.
- `spare` — запасные вопросы.

## Устройство

- `index.html` — страница
- `blank.html`, `blank.pdf` — бланк ответов для печати
- `css/style.css` — дизайн (цвета тем — в начале файла)
- `js/data.js` — содержимое викторины
- `js/app.js` — слайды, навигация, таймер
- `js/sound.js` — сигналы таймера
- `assets/answers/` — картинки к ответам: подшива (вопрос 3), погоны старшего сержанта (4) и ефрейтора (14)
- `assets/fonts/` — шрифт Onest (лицензия SIL OFL)
