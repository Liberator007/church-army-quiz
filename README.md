# Викторина «Слепи ответ»

Сайт-презентация для проектора: показывает вопросы, время на ответ и ответы.
Вся викторина — один раунд в формате «Слепи ответ»: команды слышат загадку, ответ на которую — предмет,
и лепят его из пластилина. Оформление — в армейских тонах (олива, хаки, латунь), спокойное и современное.
Работает **без интернета** и без установки — это обычные HTML-файлы.

Структура и управление взяты из викторины [homechurch-quiz](https://github.com/Liberator007/homechurch-quiz)
(её первый раунд).

## Как запустить

1. Скачать репозиторий: на GitHub **Code → Download ZIP** (или `git clone`), распаковать.
2. Открыть `index.html` в **Google Chrome** (двойной клик).
3. Перетащить окно на проектор и нажать **F** — полный экран.

Если что-то не грузится из файла (бывает в некоторых браузерах), запустите маленький сервер
в папке проекта и откройте http://localhost:8000:

```
python3 -m http.server 8000
```

## Как устроен показ

**Заставка → суть игры → вопросы → ответы → конец.**

- Вопрос: сначала на экране только его номер, по клику открывается сам вопрос и запускается время
  (1 минута на обсуждение и лепку, таймер справа). Следующий клик — следующий вопрос.
- После последнего вопроса — список всех вопросов. Ответы открываются по одному, по клику.
  Пояснение видно у последнего открытого ответа.
- Запасной вопрос открывается через **O**; если его показывали, его ответ появится в списке ответов.
- Если номер перед вопросом не нужен, поставьте `numberFirst: false` в начале `js/data.js`.

## Управление

| Клавиша | Что делает |
|---|---|
| **Клик мышью**, **→**, **Пробел**, **PgDn** | Дальше: открыть вопрос и запустить время → следующий вопрос → открыть следующий ответ |
| **Правый клик**, **←**, **PgUp** | Назад (в списке ответов — скрыть последний открытый) |
| **P** | Пауза / продолжить время |
| **R** | Запустить время заново |
| **O** | Список всех слайдов, переход в любое место, **запасные вопросы** |
| **F** | Полный экран |
| **T** | Светлая («хаки») / тёмная («ночная олива») тема |
| **B** | Чёрный экран |
| **M** | Выключить / включить сигналы таймера |
| **H** | Подсказка по клавишам |

Пульт-презентер работает (он нажимает PgUp / PgDn). Клавиши работают и в русской раскладке.
При движении мышью в правом нижнем углу появляются кнопки ведущего.
Сайт запоминает, на каком слайде вы остановились.

## Как поменять тексты

Все вопросы, ответы, суть игры и время — в файле `js/data.js`. Его можно редактировать прямо на GitHub.

- `title`, `subtitle` — заголовок и строка над ним (дата, событие) на заставке.
- `about` — суть игры; `**текст**` выделяется.
- `phases` — время на вопрос (можно несколько фаз — тогда под таймером появится их список).
- `questions` — вопросы: `text` на экране, `short` для списка ответов, `answer`, `note` — пояснение.
- `spare` — запасные вопросы.

## Устройство

- `index.html` — страница
- `css/style.css` — дизайн (цвета тем — в начале файла)
- `js/data.js` — содержимое викторины
- `js/app.js` — слайды, навигация, таймер
- `js/sound.js` — сигналы таймера
- `assets/fonts/` — шрифт Onest (лицензия SIL OFL)
